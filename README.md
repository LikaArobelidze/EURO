# EUROINS — მთავარი ბანერის ვარიანტები

გაყოფილი ბანერი ორი ფოტოთი (სამოგზაურო და ვიზიტორთა დაზღვევა) და მაუსის ეფექტის **სამი ვარიანტი**.

## ნახვა

- `index.html` — **ხუთი ვარიანტი** ერთმანეთის ქვემოთ (მთავარი)
- `overlap2.html` — გადაფარვის დამატებითი იდეები (E–I)
- `overlap.html` — გადაფარვის პირველი ჩანახატები
- `hover.html` — მხოლოდ ერთი ვარიანტი (ზუმი და დაბნელება)
- `autoplay-slider.html` — ადრინდელი ვერსია, სადაც ფოტოები თავისით ენაცვლებოდა

გახსენით `index.html` ბრაუზერში, ან ჩართეთ GitHub Pages და გაიხსნება მისამართზე
`https://<user>.github.io/EURO/`.

## ვარიანტები

ყველა ვარიანტი **გადაფარვის ლოგიკაზეა**: გაყოფა 60% + 44% (ჯამში 104%), ანუ ფოტოები
ერთმანეთს 4%-ით ფარავენ და გამყოფი შუაში არ დგას. მაუსის მიტანაზე არჩეული ფოტო
ფართოვდება და მეორეს ჩრდილით გადაეფარება.

| | ეფექტი | რა ხდება მაუსის მიტანაზე |
|---|---|---|
| **A** | ყვითელი ხაზი | სათაურის ქვეშ ყვითელი ხაზი იზრდება, ტექსტი ოდნავ იწევა, მეორე მხარეს მსუბუქი ფარდა ეფარება |
| **B** | მინის ეფექტი | მეორე მხარე ბუნდოვანდება და მუქდება, არჩეული ფოტო ოდნავ მიუახლოვდება |
| **C** | ყვითელი კუთხე | არჩეულ მხარეს ზედა და მარცხენა ხაზი იხატება; მეორე მხარე უცვლელი რჩება |

## საიტის პარამეტრები

დიზაინი euroins-website-ის ტესტურ გვერდს ეყრდნობა:

- შრიფტი **FiraGo** (`fonts/`), სათაური 60px / 700
- ღილაკი: ფონი `#FFC500`, ტექსტი `#0A0A0A`, სრულად მომრგვალებული
- ბანერის სიმაღლე 736px, გაყოფა 50/50
- ტექსტის დაშორება მარცხნიდან 24 / 40 / 80px ეკრანის სიგანის მიხედვით
- ყვითელი ხაზი და ღილაკი ორივე მხარეს ერთ სიმაღლეზეა (ბლოკი ქვემოდან ითვლება)
